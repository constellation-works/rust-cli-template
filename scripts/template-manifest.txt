# What scripts/init.sh removes, rewrites or replaces for each kind, and what
# scripts/check-template.py checks. One entry per line:
#
#   example PATH               the note example; removed by cli-bare and workspace
#   crates PATH                the crates; removed by workspace
#   template PATH              the template's own; removed by every kind, and a
#                              change to it needs no version bump
#   regions PATH               a file with marked regions (below)
#   generated PATH             rewritten by init.sh in every kind
#   overlay KIND PATH SOURCE   for KIND, SOURCE (a template path) replaces PATH
#
# Regions are lines between a begin and an end marker, written in the file's
# own comment syntax, e.g. `// example:begin` or `<!-- example:end -->`:
#
#   example:begin / example:end    removed by cli-bare and workspace
#   crates:begin / crates:end      removed by workspace
#   template:begin / template:end  removed by every kind; inside one, a line
#                                  `copy: <text>` becomes <text> in the copy,
#                                  with __VERSION__ and __KIND__ filled in
#
# Each kind drops only the marker lines of a region it keeps. Outside these
# entries and regions, no shipped file names the note example.
