Keep short notes in a local store

Usage: tmpl-cli [OPTIONS] <COMMAND>

Commands:
  note  Add, list and show notes
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --root <DIR>       Data directory [default: $TMPL_CLI_ROOT, else ~/.tmpl-cli]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $TMPL_CLI_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  tmpl-cli note add "Call the plumber" --tag home --priority high
  tmpl-cli note list --tag home
  tmpl-cli note show <id> --json
  tmpl-cli note list | cut -f1,3

Exit status: 0 on success, 1 when a command fails, 2 on a usage error.
